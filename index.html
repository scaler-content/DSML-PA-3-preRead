The Analyst Files · Case #03
THE FITNESS-APP FUNNEL
Fitness / Interview

Setup

You're across the table in a product-analytics interview. The warm-up's done. The interviewer leans in: “A fitness app called PureFit wants to improve retention. What metric would you look at?” You have the framework. Now run it — live, out loud, under pressure.

Evidence

  • PureFit has free and paid tiers. “Retained” means still active after two months.
  • The user funnel: acquisition → onboarding → engagement → retention.
  • Last month the app added new users, but day-60 active users aren't growing proportionally.

The Mystery

Before the interviewer's second question lands — what's the first metric you'd define, and at which funnel stage?

Make Your Move

Why this move

There's no universally “right” stage to start — but there is a structured reason to start somewhere.

Section 2

Real-World Use Cases

PureFit FunnelNaukri tracks application-completion rate as its core engagement metric — a user who searches but never applies is browsing, not engaging. Same logic as PureFit's class metric.
WAU / MAUWhatsApp defines “active” as sending one message in 30 days. The reported MAU is meaningful precisely because the threshold is hard to fake.
Nth-Day RetentionDuolingo uses day-1, day-7, day-30 retention as core health metrics. A day-7 drop says the onboarding habit isn't sticking — a specific, fixable problem.
Classes / DurationPeloton weights “rides completed” over “rides started.” Completion signals value; abandonment at minute 3 is a product problem, not a motivation one.
Referral RateDropbox measured referred users' 30-day retention separately — they retained better, which justified doubling the referral incentive.
Bank App RevenuePhonePe tracks “transaction value routed through app,” not just downloads. App revenue metrics must tie to money moved, not user presence.
